# Dubai Real Estate Analytics Dashboard

## Overview
An end-to-end Data Analytics portfolio project inspired by Bayut & dubizzle.

## Tech Stack
- SQL
- Python (Pandas)
- Power BI
- GitHub

## Dataset
Synthetic Dubai property listings dataset with 10,000 records.

## KPIs
- Total Listings
- Average Property Price
- Median Price
- Price per Sq. Ft.
- Listings by Area
- Property Type Distribution

## Dashboard Pages
1. Executive Overview
2. Area Performance
3. Price Trends
4. Property Type Analysis
5. Interactive Map

## Key Business Questions
- Which areas have the highest average prices?
- Which property types dominate inventory?
- Which locations generate premium price per sq. ft.?
- How has pricing changed across years?
